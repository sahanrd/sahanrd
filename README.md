### 🚀 About Me

Hey there! 👋 I'm **Sahan Dissanayake**, a passionate **Creative Web Developer** based in Kandy, Sri Lanka 🇱🇰. 

I specialize in building visually captivating, interactive 3D web experiences and full-stack web applications.

- 🎨 **3D & Motion Web:** Crafting WebGL canvas scenes with **Three.js** & scroll FX with **GSAP**.
- 🌐 **Web Applications:** Developing dynamic web apps using **PHP**, **JavaScript**, **MySQL**, & **Firebase**.
